# **Лабораторная работа № _ 1__** 

# **Тема:** 

Исследование и моделирование процессов движения информации методом структурного анализа на основе DFD-диаграмм с использованием CASEсредства поддержки моделирования потоков данных 

# **Цель:** 

 изучить общие положения о моделировании потоков данных и компоненты диаграммы потоков данных DFD; 

 осуществить исследование и моделирование процесса движения информации методом диаграмм потоков данных (DFD диаграмм); 

 осуществить выбор и применение инструментального средства для функционального моделирования потоков данных (диаграммы DFD). 

# **Основная часть** 

1. Отчет о выполнении практического задания 

1.1 - В рамках выполнения практического задания была проведены работы по ознакомлению с теоретическим материалом и установке приложения Ramus. 

1.2 - Исходя из постановки задачи будет рассмотрена информационная система видеоигры. Дальнейшее выполнение происходит в блоке задач лабораторной работы. 

2. Отчет о выполнении задания на лабораторную работу 

2.1 - Было проведено исследование доступного функционала кроссплатформенной системы моделирования и анализа бизнес-процессов RamusEducational. Далее приведено краткое описание результатов данного исследования. 

При создании проекта (Рисунок А.1 – А.5) было предложено привести основные параметры проекта и модели: Имя автора, Название проекта, Название модели, Организацию пользователя, Краткое описание, Классификации и их отношения. 

Основное окно (Рисунок А.6) по умолчанию использует шаблон “Диаграммы”, шаблоны меняют и скрывают основные окна программы, так шаблон “Диаграммы” открывает панель “Модели”, окна “<Название модели>”, “Редактор атрибутов элемента”, “Редактор атрибута”, а шаблон “Навигатор по модели” (Рисунок А.15), открывает “Навигатор по модели”. 

Шаблоны находятся на правой части панели, находящейся выше окон. В левой части панели находятся кнопки взаимодействия с моделью, такие как размещение объектов моделирования потов данных (диаграммы DFD), отмена действия, возврат к отмене, предварительный просмотр, печать, переход на уровень ниже и выше диаграммы (к дочерним и родительским диаграммам). 

В самой верхней панели находятся выпадающие меню. Так “Файл” позволяет производить взаимодействия с файлами, такие как сохранение, открытие и создание нового файла. “Диаграммы” вмещает в себя расширенный функционал по работе с моделью, помимо объектов диаграммы, содержит центрирование стрелок, свойства модели и диаграммы, добавление модели из файла. “Окна” позволяет открывать нужные окна в обход шаблонам. Прочие меню содержат функционал, нужный в особых ситуациях, таких как описание программы, свойства проекта или открытие проекта в веб-браузере, поэтому для сокращения описания не будут рассмотрены. 

2.2 – Был проведён анализ внешних событий (определены внешние сущности) исследуемой предметной области, оказывающих влияние на функционирование системы. 

Так существует некоторый игрок, который получил в собственное распоряжение копию видеоигры. Игрок может производить взаимодействие с системой, через ввод с клавиатуры и мыши. Существует и команды разработчиков и тестировки, которые модифицируют данную систему.

- Игрок(/и)

- Команда тестировки 

Производят они внешнее событие: 

- Взаимодействие и модификация системы.
